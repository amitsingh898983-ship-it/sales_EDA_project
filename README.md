# sales_EDA_project
📌 Overview

This project focuses on analyzing and visualizing data to uncover meaningful insights. Using Python visualization libraries, the dataset is explored through charts and graphs to better understand patterns, trends, and relationships.

🎯 Objectives

Clean and preprocess the dataset

Perform exploratory data analysis (EDA)

Create meaningful visualizations

Identify trends, patterns, and correlations

📁 Dataset

The project works with a structured dataset (CSV format).
The dataset may contain numerical and categorical features used for analysis and visualization.

📊 Visualizations Included

📈 Line Charts – Trend analysis

📊 Bar Charts – Category comparison

🥧 Pie Charts – Proportion analysis

📉 Histograms – Distribution of values

🔥 Heatmaps – Correlation between variables

📦 Box Plots – Outlier detection
